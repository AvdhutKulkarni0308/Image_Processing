# 📚 Theory

## Image Forgery Detection

Image forgery detection identifies manipulated or tampered regions in digital images.

Common types of image forgery include:

* Copy-Move Forgery
* Splicing
* Retouching

Machine learning techniques analyze image features to classify images as:

* Original
* Forged

---

# 🤖 Machine Learning Approach

The system performs the following steps:

1. Image Preprocessing
2. Feature Extraction
3. Model Training
4. Classification
5. Prediction of Forged/Original Images
